## Pilot Package

**Best for:** First-time customers validating spatial positioning in a defined area.

**Scope:** One zone, route, floor, or outdoor AOI.

**Duration:** 4–6 weeks after site/data access is confirmed.

**What's included:**
- Site/data scoping call
- VPS map or synthetic/demo map preparation
- Web portal scene setup
- Localization API endpoint
- Unity SDK or Navigatus integration (one)
- Up to 5 persistent AR anchors
- Accuracy and reliability report
- Final recommendation: Go / Conditional / No-Go for rollout

**Pricing:**
| Venue complexity | Fee |
|---|---|
| Small venue (single room, corridor, showroom) | USD 8,000 – 12,000 |
| Medium venue (multi-room floor, retail destination) | USD 12,000 – 15,000 |
| Enterprise or complex facility | USD 20,000 – 40,000 |

**Conversion credit:** Up to 50% of the pilot fee is credited toward a Venue or Network annual contract if signed within 60 days of pilot delivery.

## Venue Package

**Best for:** Customers who have completed a pilot and want to deploy across a full venue or facility.

**Scope:** Full building, campus zone, or outdoor venue.

**Duration:** Ongoing (12-month minimum contract).

**What's included:**
- Full-building or full-venue VPS map coverage
- Unlimited anchors
- Multi-floor map support
- Hosted localization API (S3 or Azure storage backend)
- Unity SDK and Navigatus integration
- Web portal with scene management
- API key management
- Priority support (48-hour response SLA)
- 99% monthly uptime commitment
- Quarterly accuracy review
- Rollout expansion support

**Pricing:** Provided on request based on:
- Number of floors / zones
- Estimated localization queries per month
- Custom integration scope

**Indicative range:** USD 2,500 – 8,000 / month depending on scale.

## Network Package

**Best for:** Enterprise customers, AR agencies, and property networks deploying across multiple sites.

**Scope:** Multiple sites, enterprise console, partner/agency resale rights.

**Duration:** Annual contract, minimum 2 sites.

**What's included (all Venue Package features, plus):**
- Multi-site management console
- Tenant/project isolation per site
- Partner / agency sub-licensing rights
- Dedicated account manager
- 99.5% monthly uptime commitment
- Custom SLA options
- Quarterly business review
- Early access to new features

**Pricing:** Pricing on request. Structured as:
- Per-site onboarding fee
- Monthly platform fee (per active site)
- Volume discount for 5+ sites

## Important Notes

1. **Synthetic data benchmarks are not production SLA claims.**
   Google 3D synthetic data is used for research, pretraining, and outdoor demo acceleration. Production accuracy guarantees apply only after real-device validation in the target environment.

2. **Custom Unity or WebAR integration is out of scope** unless explicitly included in the agreed pilot/venue contract. Custom development is billed separately at agreed day rates.

3. **Pilot fees are non-refundable** but may be partially credited toward an annual contract as noted above.

4. **Storage and cloud hosting costs** (AWS S3, Azure) are passed through at cost for Venue and Network tiers. Pilot tier uses local storage by default.

5. **Pricing is subject to change.** These rates reflect pilot-stage pricing. Rates for Venue and Network packages will be confirmed in a formal proposal.
